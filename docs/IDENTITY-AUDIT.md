# Fictional identity check

Checked 24 October 2026 before publication, using exact-name web searches for all 16 fictional club display names. This is a practical collision screen, not a trademark registration search.

Two initial names were discarded:

- **Aurora Milano**: the real ASD Aurora Milano operates at https://www.auroramilano.it/ and appears in the Italian Olympic Committee registry. Replaced with **Vespera Milano**.
- **Northstar City**: a real Aberdeen grassroots football team appears at https://www.teamstats.net/team/football/northstar-city. Replaced with **Kestrel Quay**.

The retained identities are Cakrawala Junior, Surya Kota FC, Banyu Biru, Meranti Athletic, Garuda Selatan, Lentera United, Seabrook Rovers, Solana Deportivo, Arunika Jakarta, Portovento Calcio, Rheinwald 08, Belrive Olympique, Valente Real, Vespera Milano, Kestrel Quay and Monteluz CF. Searches did not reveal a direct football-club match for the other exact names. The search is not proof that no conflicting name exists.

Crests are original geometric monograms. Kits use independently chosen abstract color pairings; no real sponsor, athlete likeness, official logo or jersey pattern is used. Real geographic names provide fictional settings only. The project title KICKTALE comes from the user's brief.
